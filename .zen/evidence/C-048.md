# C-048 evidence - the supervisão file and the binding file

## The design (2026-11-09)

The design's first open point (`docs/design/supervisao/README.md`, "the binding file format")
settled as two files, both read by core's header reader: the host file (`veredas-supervisao` v1:
the address, the sessions) and the binding file (`veredas-binding` v1: a session's objects, the
layout, the headline, the dashboards). The reference is `docs/binding-schema.md`; its worked
example is four blocks (the host, the portal project it runs, the binding, the SVG) that the
files test writes under the names they give and loads, and that the live tests of the other
clauses run against the bench (the endpoint, the namespace and the port substituted).

A binding is checked against what its project carries when it loads, never left to light up or
not at run time: every source a binding names is the project's, every series one that source
carries (a capture rule's value groups for a log the rule reads, the key group excluded; an OPC
tag's or bit's series; a catalog message's fields), with the series it does carry named in the
refusal; every write an OPC tag a rule marks writable, named by its node id text, as portal's
write surface names it (the reference first named it by its series, which portal would have
refused: corrected before any code, `docs/binding-schema.md`); every table a capture rule, an OPC
rule, a message or a view. A view's columns are the engine's to judge, so a table panel's columns
are checked when the panel is computed, and a panel that cannot be computed says why in its place
(C-052).

The layout is read as XML (`roxmltree`), never by a pattern over its text (portal's lesson: a
reading of SQL was the wrong tool for five rounds). A layout is a drawing the page places in its
own document, so a script, foreign content or an event handler refuses it at load.

A panel's keys are read per kind from a TOML table (serde with `deny_unknown_fields` per kind), so
a key another kind takes is refused with the keys this kind takes, never swallowed (portal's
untagged-enum trap).
