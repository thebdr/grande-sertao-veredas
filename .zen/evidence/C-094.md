## Choices

- A break only when context is asked (grep prints `--` only then); a first version broke between
  two matches with no context, which the test caught.
- A binary file is one with a NUL in its first 8 KiB unless the head reads as UTF-16 (its zeros are
  text): skipped quietly and counted, searched when asked.
- A cancel is checked before each file and every 4 096 lines inside one.
- The whole file is read into memory before it is searched; the size guard bounds that.

Thirteen mutants each turn the test red (xor as or, the negation ignored, a break without context,
the binary guard off, UTF-16 taken for binary, either cap off, the cancel unheard inside a file
(first surviving, killed once the test cancelled inside one large file), the whole word off, an
overlap kept, the masks ignored, the tree unsorted, the context before dropped).

## Refute round 1 (2026-11-23, at 713e3ed): refuted, six gaps

1. **Decoded otherwise than the tail**: the grep fed a whole file to the decoder at once, the tail
   feeds it in 64 KiB slices, and the decoder settles UTF-8 or CP1252 on the slice holding the
   first byte past ASCII. A file opening in UTF-8 with one CP1252 byte 71 KB later read as UTF-8
   in the tail and as CP1252 in the grep, `Produção` found by neither the eye nor the query. The
   grep feeds the tail's own slices now (`tail::READ_CHUNK`), and the test compares its lines with
   the live tail's for the same file.
2. **Whole word inverted at a pattern's non-word ends**: `\b(?:p)\b` matched `-5` glued in `a-5 b`
   and missed it alone. Built on the engine's half word boundaries now (`\b{start-half}`,
   `\b{end-half}`): standing apart from word characters on both sides, as Veredas 1's `word(true)`.
3. **`?` matched a byte**: an accented letter is two. Masks are matched by character now.
4. **Links followed**: a `loop -> .` searched one file 41 times, a `latest ->` folder would be
   searched twice. The walk follows no link, to a folder or a file, as Veredas 1's
   (`follow_links(false)`, files only).
5. **The refusals' words unasserted**: the engine's own words are asserted now (an unclosed group,
   look-around not supported).
6. **"Opened for reading alone" unasserted**: a read-only file is in the tree test now, searched
   with no error.

Seven mutants, each red now: the engine's words dropped from a refusal, every file opened for
writing too, the whole file decoded at once, the whole word by `\b`, masks by byte, links to
folders followed, links to files read.
