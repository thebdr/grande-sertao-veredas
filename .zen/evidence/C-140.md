# C-140 evidence - what a frame says

## The observations (2026-11-24)

Phase 4's second piece, on the wire seam (C-139): what each kept frame says about one device, with
its witness. Absorbed from Veredas 1's `observe.rs` (`/home/thebdr/code/Veredas`, branch
`supervisao-plan`), changed on the way:
- **The witness's time is the frame's nanosecond stamp** and its frame index a `u64`, from the seam.
- **Damage is a list of named problems**, each kept (Veredas 1 kept one string); a DCP block that
  does not fit its kind is named with its option and suboption while the rest is observed (the
  codec keeps it damaged, C-132), and an LLDP PDU that is none (an unfit mandatory TLV in its place,
  C-133's sixth round) observes nothing.
- **An LLDP frame or an ARP sender from a group address** is damage too (Veredas 1 checked DCP's
  source alone); an ARP packet that is not Ethernet's and IPv4's, or of another operation, is
  damage named, where Veredas 1 passed over it silently.
- **The class is a type**, named in a count as Veredas 1's strings were (`dcp` for its
  `profinet-dcp`, `cyclic` for `profinet-rt`, with the alarms and the other PROFINET ids apart), read
  back from its name, an unknown EtherType as `other:0x....`.
- The subject's rule (the MAC a frame names for its device) is kept: an LLDP PDU's chassis MAC TLV,
  else a MAC chassis id, else its source; fusion (next) matches a local chassis id to a station
  name it already knows.

Before the first commit, 18 mutants of `observe.rs` (each rule of what is observed, each group
source refusal, each ARP check, the classes of each PROFINET range and two EtherTypes, the subject's
order, the damage of a block, the witness's index) were run against the tests: 17 killed, and the
subject's order (a MAC chassis id read before the chassis MAC TLV) killed once a PDU holding both,
differing, was added.
