# C-018: An OPC source compiled: lab notebook

## The port (2026-11-06)

From Veredas 1's `crates/veredas-opc/src/spec.rs` and its inline tests, now `src/opc/spec.rs` and
`tests/opc_spec.rs`.

What changed:
- **`parse_node_id` returns a `NodeIdError`, not a `String`.** `Empty` covers blank text and
  `Malformed` quotes the trimmed input. Each displays Veredas 1's words.
- **The writable and polled lookups trim the configured text too.** Veredas 1 trimmed only the
  request, so a tag configured with a stray space could never be written.
- **The docs name no caller.** Veredas 1's named the desktop, its editor, the credential store,
  the dashboard and a plant.

New tests:
- every node id form, and the round trip of the text form;
- the refusals' exact texts;
- the first-seen order;
- an empty spec;
- the bit columns' type;
- whitespace on the configured side;
- the label.

## Refute round 1 (2026-11-06): refuted, test gaps only

The code held, but two mutations of `writable_tag` survived the suite:
- **A prefix match.** A blank request, or a prefix of a writable tag's text, would have reached
  the wire.
- **A lookup by parsed node.** `ns=01;s=cmd` would have matched `ns=1;s=cmd`. The "equivalent
  spelling" the test claimed to try was another node, `CMD`.

Now pinned for both lookups:
- a blank request;
- a prefix, an extension and a truncation;
- `ns=01;s=cmd`.

Also found: `Auth` derived `Debug`, which printed the password. It is now written by hand,
showing `<hidden>`, and pinned through a spec's debug form.

Held:
- parsing against the stack's own grammar (nine more malformed forms, Unicode blanks as empty);
- every mutation of `parse_node_id`, `columns` and `poll_nodes` tried;
- dropping the writable check or either trim.

## Refute round 2 (2026-11-06): refuted, one test gap

Both round-1 mutations now fail the suite. One more survived: matching on the END of the
request (`raw.ends_with(configured)`). No negative case ended with a writable id, so
`ns=2;s=ns=1;s=cmd` (a valid id for another node) would have reached the wire.

Now pinned for both lookups: `ns=2;s=ns=1;s=cmd`, `Xns=1;s=cmd` and a doubled id.

Held:
- the debug forms, in every shape;
- the other lookup mutations: contains, starts_with either way, case, spaces, one-sided trims.

## Refute round 3 (2026-11-06): refuted, test gaps

The `ends_with` mutant is now killed. Two more survived, because every tag in the test was
configured in the spelling the stack prints, so text and node comparisons agreed:
- `writable_tag` comparing against the printed node;
- `poll_nodes` deduplicating by text.

Now tags are configured as `ns=0;i=5` and `ns=01;s=cmd`:
- each is found by that text, not by `i=5` or `ns=1;s=cmd`;
- three spellings of one node, the last one the stack never prints (`ns=00;i=5`), are polled once.

Both mutations were applied to the real code by hand and fail the suite. The first version of
this test, without `ns=00;i=5`, let the dedup mutant through; that is why the third spelling is
there.

## Refute round 4 (2026-11-06): refuted, test gap

The round-3 mutants are killed. One survived: deduplicating on the id value alone, ignoring the
namespace. Every fixture had one node collapsing to one; none had two different nodes sharing an
id. Such pairs are common: a namespace per device reuses tag names.

Now pinned, all four kept in first-seen order:
- `ns=2;s=Temperature` and `ns=3;s=Temperature`;
- `ns=1;i=5` and `ns=1;s=5`.

The mutation was applied by hand and fails.

Recorded, not counted: the same text configured once read-only and once writable resolves as
writable. The clause does not decide this, and refusing it would open no hole.

## Refute round 5 (2026-11-06): refuted, minor test gap

Round 4 is closed: both dedup mutants fail. The opaque `b=` form was checked only for parsing and
its namespace. A mutation decoding it as a string id (another node) survived, as would a library
upgrade that decoded it differently.

The opaque and guid forms are now pinned by identifier kind, and the opaque one by its text
round trip. The mutation was applied by hand and fails.
