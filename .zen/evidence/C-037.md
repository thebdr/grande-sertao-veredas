# C-037 evidence - backfill

## The design (2026-11-07)

Veredas 1's `tail/backfill.rs` as it was: the plan (files, first offset, encoding, skipped
members), the peek over buffered reads, the raw line table per encoding. Its unit tests moved
into the clause's test file through two doc-hidden functions (`plan_for`, `line_table`) that
expose the plan and the table without making the internals public API.

Added over Veredas 1's tests: an unstamped continuation line before the start skipped (it belongs
to the earlier stamp), the refusal's text when a backfill is asked without a timestamp rule, the
first replayed line's stamp and index at the seam, and a backfill into an empty folder falling
through to a live attach that reads what is born whole.
