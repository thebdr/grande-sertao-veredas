# C-138 evidence - the records a read returns

## The codec (2026-11-22)

New in Veredas 2: what phase 6 reads of a device by the implicit read (C-137): I&M0 for deep
identity, and the port's real data for the device-to-device links passive LLDP cannot give (the
plan's trap). Checked against tshark 4.6.6's PNIO dissector, reading the records inside read
answers, before the tests were written.

What the dissector settled:
- **Only block version 1.0 is read** for both records: 1.1 is "not implemented yet!" at warning
  severity. The codec reads 1.0 alone and refuses another version by name.
- **The port's data aligns its fields to four bytes from the block's start** (the block type's
  first byte), not from the body: the padding after the number of peers, after a peer's chassis id,
  after its MAC, after the MAU type and after the link state.
- **A peer's delay word has a format bit**: bit 31 set, the dissector reads bits 0 to 30 as the
  cable delay (`cable_delay_value`), clear as the line delay (`line_delay_value`).
- **Bytes after the medium are ignored** by the dissector, with no complaint; the codec keeps them
  as heard, so a later version's fields are not lost on the way back.
- **The software revision's prefix is a character**: the dissector shows it quoted (`'V'`).

Before the first commit, 22 mutants of `record.rs` were run against the tests: 20 killed, two
survivors (the link's up test saw only links 1 and 2; the I&M version 1.1 read the same both ways
round), each killed by a test added.

## Refute round 1 (2026-11-22): refuted, the code right, the fixtures too quiet

The critic sent non-zero values of every field through tshark (slot 7, profile 0xF600, a tilde in
each text, a MAC of six different bytes) and read each back as written; fuzzed 400 000 bodies with
no panic and every accepted body written back to its bytes; and found every count right. But the
tests held most numbers at 0 or under a byte, so 17 mutants passed: the port's slot written as 0
or before its padding, I&M0's profile id and type swapped, the revision's internal number dropped,
a version or type checked by its low byte only, the visible range losing its tilde, a peer MAC's
middle bytes swapped, the high bytes of the MAU type, the boundaries, the medium and the vendor id
dropped. The fixtures now carry each field distinct and past a byte, tildes in every text, slot 7
in the read answers tshark reads, and versions and types differing in either byte. The 256-peer
refusal had borrowed a length error whose words were false ("255 bytes after its version"); it
has its own now. Before this commit, the critic's 17 survivors and three more were run: all
killed.
