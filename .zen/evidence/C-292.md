## The first machine (2026-11-22)

Release 2.0.0-alpha.1's OVA (1.09 GB) built in about 12 minutes of provisioning and proven by
`entrega prova`: the release's sums checked at boot, the plant live from the host, the offered
write refused, Chromium on the page (target/entrega/2.0.0-alpha.1/prova/proof-screen.png). Its
first recorded run of the test failed on the test's own listing (`root/root` where `--numeric-owner`
writes `0/0`); the second passed (about 50 minutes: a trial cut, the machine, the proof).

## Refute round 1 (2026-11-23)

Refuted, two findings and a minor one:
- The screen check counted colours (more than 200): with the browser painted flat white the real
  dump still showed 505, the wallpaper alone 217. A machine whose browser never opens the page
  passed.
- `entrega prova`, the proof the clause names, checked less than the test: no card line, and the
  OVA's descriptor and manifest never read, so an OVA VMware would refuse passed it, and the
  first release's machine (built before the card line) passed it too.
- The test wrote `vmx-{}` where the descriptor writes `vmx-{:02}` (only below version 10).

Answered: the proof polls screen dumps until the page's own canvas colour, read from the
release's page at its commit, covers 15 % of the screen (`share_of`, `page_canvas`); `ova_faults`
reads the OVA as VMware reads it, and `proof_faults` holds it, the card line and the page; the
test asserts the same and writes `vmx-{:02}`. Light tests in tests/prova.rs pin each case without
a machine. The first release's OVA, built before `--mode` and the card line, is built again.
