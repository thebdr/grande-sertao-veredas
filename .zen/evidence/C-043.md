# C-043 evidence - the session

## The design (2026-11-07)

Veredas 1's desktop session (its ingest pump, its live caches, its health) moved out of the shell
into the library, so a shell, the server and controlador embed the same thing: the `session`
module behind the `store` feature. What a reader needs every second (the series listing, the
vitals, the health, the counters) is kept by the ingest, never queried from the store: Veredas 1
found at a plant's scale that a listing by store scan ran for minutes holding the store's one
connection, and every endpoint convoyed behind it.

Three protocols feed one store through one pump thread: a captured line, a mapped poll and a read
message each become a wide row of the table their rule or message names, and every value a
sample the frames broadcast. A message table is named by the message alone (C-041), so the
session refuses a name taken twice across rules, OPC rules and channels, naming both owners,
before anything spawns.

Health folds the worker's liveness with the arrival age on the arrival clock. A quiet log and a
share away read alike (idle): a tail cannot tell them apart, and the clause says so rather than
claim it. A server or a peer away is retrying, which is alive and self-healing, never failed; only
a worker that ended in error is failed. The refresh runs every 500 ms, so a test's idle window must
be longer than that or the live state ages into idle before it is seen (the first health test did
that, with a 400 ms window).

The master switch is the one `WriteGate` every OPC handle and channel handle of the session
shares (C-040, C-039): there is no second gate here, so it cannot drift from what the handles
enforce; the session only exposes it, live.

## Reconcile (2026-11-08): the project and the session check alike

The implications check against C-041 and C-046 found the channel clause miscited (C-038 for
C-039), two validators drifting (the project compared table names by case and refused a view
named like another view; the session compared without case and let two views share a name), and
checks the session ran that the project skipped. The two now claim names through one type
(`project::Claims`, case-insensitive, views included), the channel is checked whole before anything
spawns (`channel::check`: framing, reply rules, tables), and the clause names what it refuses.
