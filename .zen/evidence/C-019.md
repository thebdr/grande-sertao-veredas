# C-019: An OPC value into the value model, and bits out of words: lab notebook

## The port (2026-11-06)

From Veredas 1's `crates/veredas-opc/src/value.rs` and its inline tests, now `src/opc/value.rs`
and `tests/opc_value.rs`.

What changed (bugs Veredas 1 carries, worth porting back by whoever owns it):
- **Bits are read at the wire word's own width.** Veredas 1 widened to `i64` first, so a negative
  word was sign-extended:
  - bit 20 of an Int16 −1 read 1, though Veredas 1's own comment says past the word reads 0;
  - a UInt64 above `i64::MAX` was "not an integer" and had no bits at all.
- **A 64-bit field whose top bit is set is refused** (`FieldOverflow`). Veredas 1 wrapped it to a
  negative `Int`.
- **A status code renders into a `Text` series as its name.** The stack's `Display` gives
  `StatusCode(BadNodeIdUnknown (2150891520))`.

New tests:
- every integer type at both edges;
- every series type for an empty value;
- the time path;
- the exact texts;
- each signed width.

## Refute round 1 (2026-11-06): refuted

- **Some refusals did not name the wire type.** Five of the stack's types fell into a catch-all
  `"unsupported"`: ExtensionObject, XmlElement, a nested Variant, DataValue and DiagnosticInfo.
  So a structure mapped to an int read "unsupported value does not fit a int series".
  - `wire_name` now names every variant, with no catch-all, so a type the stack adds is a
    compile error.
  - Each of the fifteen non-numeric types is now pinned refused, by name, four ways.
  - The clause now says an empty value's refusal names no type.
- **Test gaps:**
  - nothing read bits from a Byte, so a sign-extending or missing Byte arm survived;
  - nothing pinned that a non-integer is refused at bit 64 or above, so moving the
    bit-64 check first survived.

  Both are pinned now.

Held:
- every integer edge, and the float and time paths;
- the exact texts;
- each sign-extension and width mutation tried.

## Refute round 2 (2026-11-06): refuted, one test gap

All three round-1 findings are closed. Seven numeric wire names (Boolean to UInt32) were in no
assertion, because a number can be refused only as a time. A slip such as `UInt16 => "Int16"`
would have survived. Each of the eleven numeric types is now pinned refused as a time by its own
name.

Held:
- every wire type named;
- a nested Variant, and an empty array, rendered as text without a panic.
