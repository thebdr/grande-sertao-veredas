# C-004 evidence - core depends on no other member

## Refute round 1 (2026-11-05)

Attacked: a dependency inherited with `workspace = true` whose `[workspace.dependencies]` entry
carries the `package` rename (cargo builds it: `cargo tree` showed `veredas-core → veredas-portal`
while the law saw `gw`, which is no member); the pre-2024 `dev_dependencies` / `build_dependencies`
spellings (edition 2021 accepts them; serde silently dropped them); dotted tables; target tables;
a path dependency under another key without `package` (cargo refuses it); an underscore key (cargo
refuses it); a self-dependency in `[dependencies]` (cargo refuses the cycle); a git or version
dependency carrying a member's name (flagged, stricter than needed, within the clause's "names").

Refuted, fixed: `deps_of` resolves a `workspace = true` entry through the root table, the member's
own `package` winning (`l4_a_dependency_renamed_in_the_workspace_table_is_seen`); the underscore
spellings are read as aliases of the hyphen ones, under the root and under every target
(`l4_the_underscore_tables_of_edition_2021_count`).

Held: target-specific tables, dotted tables, the self dev-dependency.
