# C-026 evidence - the OPC UA server

## The port (2026-11-06)

From Veredas 1's `crates/veredas-maquinar/src/opcsim.rs` and `tests/opcsim.rs`, now `src/opc.rs`
and `tests/opc_server.rs`. The threading is core's `DetachedPlant`'s (a thread, a current-thread
runtime, std channels drained on a 20 ms tick, the runtime's drop as the teardown), the server
setup core's demo plant's (bind first, advertise the bound port, the namespace apart from the
application uri, `has_type_definition` on every variable).

Changed:
- `OpcConfig` reads from TOML (`deny_unknown_fields` on every table; `type` and `access` as
  words; `randomize` an optional table; `user` an optional table whose password is hidden in
  `Debug`; `max_nodes_per_read` and `max_sessions` as the knobs core's demo had);
- the vendor command handshake Veredas 1 hard-coded (a tag whose id ended in a product's
  trigger name written 100, answered 99 then 1 after 300 ms) is a configured **reaction**:
  `on_write`, an optional `equals`, an optional target `tag`, and `then` steps at `after_ms`
  from the trigger. Detection is by polling the watched tag each tick, edge-triggered (the
  stack calls a write callback instead of storing the value, under the address-space lock, so a
  callback could neither store the value nor be told apart from a plant-side set);
- errors typed (`OpcError`: a configuration refused with its place named, the bind with its
  address, and the startup failures core's demo names); a value that does not parse is refused
  at validation, not read as the type's zero (the file is the operator's, not a live field);
- `get` and `snapshot` answer within 5 s or not at all; a `status` counts draws and reactions;
- a `relay()` on the handle: core's `Relay` in front of a server bound on `127.0.0.1`;
- no fixed credentials: a user is configured or there is none.

The test drives the server with the raw client (as Veredas 1's did) and, once, through core's
own poll worker: the consumer's whole client path (connect, poll, gated write, the bench
vanishing) against the bench, which is the point of the bench.
