# C-020: One poll into rows and samples: lab notebook

## The port (2026-11-06)

From Veredas 1's `crates/veredas-opc/src/map.rs` and its inline tests, now `src/opc/map.rs` and
`tests/opc_map.rs`.

What changed:
- **A bad read of a word polled only for its bits is reported.** It goes on the first bit
  column. Veredas 1 reported a bad read only on the tag's own column, so a bits-only word went
  silent: holes, and no failure.
- **A good status that carried no value is reported as `no value`,** not as `Good`.
- **`render_line` is one line.** A newline in a text tag broke the line Veredas 1 called
  one-line.
- **`RuleRow` derives `PartialEq`,** so the tests compare whole rows.
- **The docs name no caller.** Veredas 1's named the event feed, the trailing screen, a decision
  and a plant.

New tests:
- the samples field by field;
- holes across bit columns;
- the absent node;
- bits of a float;
- the heartbeat at its exact polls;
- one rule skipped beside another that keeps;
- a hole as a transition;
- a spec that gains a rule.
