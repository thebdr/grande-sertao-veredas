# C-050 evidence - the object feed

## The design (2026-11-09)

The feed is Veredas 1's `live.ts` moved into Rust, where its outputs can be asserted exactly: the
page receives a state, a mark, a word, a level's fill and a marker's place, and maps them onto the
drawing. Numbers come from portal's data frames (one sample each, with its key); text comes only
through the ingest's series cache, because portal broadcasts numeric samples alone; the cache also
seeds a series no frame has carried yet and heals one whose frames a lag dropped (a newer index
only).

The fold is pure (samples in, views out, the clock a parameter), so its rules are tested without
timing; the live test proves the same views reach the snapshot route and the stream.

## Found while writing the live test

- **An arrival is not a change.** Comparing whole views published every polled object every tick,
  since each poll refreshes its arrival time: a change is now any field but the arrival, which
  rides the next change and the snapshot.
- **The health lags the first value.** Right after the start, values arrived a refresh (500 ms)
  before the source's health read live, and every object read stale for that long. A source still
  waiting has delivered nothing an object could show; staleness now reads a source as away when it
  is idle, retrying, ended or failed, and an object with no value is stale on its own.

## Found in the browser (2026-11-09): waiting is also a reconnect

Driving the page against the demo plant, the bench was stopped to see objects go stale: they
stayed normal. Portal reads an OPC source reconnecting (`ConnState::Connecting`) and a channel
whose peer left as **waiting**, the same state as before a first delivery, and the feed had taken
waiting for "not away" (the startup lag above). Away is now a pure function of the health and the
count delivered (`feed::away`): idle, retrying, ended or failed, or waiting once the source has
delivered. The fold test pins all six states before and after a first delivery; the live test now
holds the plant's objects stale for four more seconds while the source tries again, and both fail
with the old rule (the mutation run on the day).

## Refute round 1 (2026-11-10, at bfaeaad): refuted, seven gaps

Two of the critic's mutations failed the test (the arrival counted as a change; waiting never
away). Its findings, and what changed (some had already been closed by b77957b, after the commit
the critic read):
1. **A startup race (CI would have flaked):** until the feed's first tick, the snapshot route
   served no objects and no status, and a test closure read an object that was not there (2 of 20
   clean runs). The feed now evaluates once before it is served; six parallel runs green.
2. **The stream's status unasserted** (a payload of `{}` stayed green): the first snapshot's and a
   status event's running, switch and health are asserted, and the source away rides the stream.
3. **A change pinned one way only** (a `same` reading state and word alone stayed green): a level
   moving inside its state, a marker moving and a marker added are changes in the fold, and a
   level's move reaches the stream live.
4. **"A status every second" unpinned** (4 s stayed green): three status events in a row, each
   within 2.5 s of the last.
5. **The health labels unpinned:** `health_label` is public and its six labels and details are
   pinned.
6. **Keyed series:** the default 10 s forget bound, one key read (closed by b77957b), the latest
   sample whatever its key are now asserted; and a real gap: a series whose keys only the ingest's
   cache had seen showed one place for ever. The fold now takes the cache's key count, and a keyed
   series never shows one place.
7. **NaN republished every tick:** a float stuck at NaN never equalled itself. Views are compared
   as the page receives them (NaN reads `null`), so it is the same as itself.
